# Embedded presentation fonts

The presentation retains Cinzel, Cormorant Garamond and DM Sans font data from the
original bundled deck. These fonts are licensed under the SIL Open Font License 1.1,
not the repository's MIT code license. Their copyright/license notices are alongside
this file. Source notices:

- [Cinzel](https://github.com/google/fonts/blob/main/ofl/cinzel/OFL.txt)
- [Cormorant Garamond](https://github.com/google/fonts/blob/main/ofl/cormorantgaramond/OFL.txt)
- [DM Sans](https://github.com/google/fonts/blob/main/ofl/dmsans/OFL.txt)

The rewritten deck embeds the same font bytes; it does not download fonts at runtime.
